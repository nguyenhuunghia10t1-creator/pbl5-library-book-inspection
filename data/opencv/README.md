# Dữ liệu OpenCV

`collection/` là đầu ra mặc định của collector: sessions, captures UUID và manifest. `validation/` giữ bằng chứng synthetic/thực tế đã thu, không phải dataset huấn luyện đã nghiệm thu.

Hai thư mục này được ignore, chỉ README được version-control. Sau clone chúng được chương trình tạo khi cần. [Chính sách dữ liệu](../README.md), [hướng dẫn capture](../../docs/COVER_CAPTURE.md).
